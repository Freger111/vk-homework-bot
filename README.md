# VK Homework Bot

Бот ВКонтакте, который решает домашнее задание по тексту или фото.

## Возможности

- Решение задач по тексту — пошагово, с объяснением.
- Решение по фото задачи: сечения, графики, фотографии учебника.
- Разбор геометрии: сечения, графики, формулы.
- Чистка LaTeX: `\sqrt`, `\frac`, `\cdot`, `$` превращаются в читаемый текст (`√`, `/`, `·`, `°`).
- Два LLM-провайдера с автопереключением: Gemini и OpenRouter.
- Длинные решения разбиваются на части (лимит ВК — 4096 символов).
- Long Poll API ВКонтакте без тяжёлых фреймворков (только `httpx`).

## Требования

- Python 3.10+
- Сообщество ВКонтакте с включёнными сообщениями и Long Poll API
- Ключ Gemini (Google AI Studio) и/или OpenRouter

## Настройка ВК

1. Создай сообщество → **Управление → Сообщения** → включи «Сообщения сообщества».
2. **Управление → Работа с API → Long Poll API** → «Включено», версия `5.131`,
   типы событий — «Входящее сообщение».
3. **Управление → Работа с API → Ключи доступа → Создать ключ**:
   дай права **«Управление сообществом»** и **«Сообщения сообщества»**.
4. ID сообщества — внизу раздела «Управление».

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env     # Windows: copy .env.example .env
```

Заполни `.env` (см. ниже), затем:

```bash
python bot.py
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `VK_TOKEN` | Токен сообщества (Long Poll) |
| `VK_GROUP_ID` | ID сообщества (число) |
| `LLM_BASE_URL` | Base URL основного провайдера |
| `LLM_API_KEY` | Ключ основного провайдера |
| `LLM_MODEL` | Модель основного провайдера |
| `FALLBACK_BASE_URL` | Base URL запасного провайдера |
| `FALLBACK_API_KEY` | Ключ запасного провайдера |
| `FALLBACK_MODEL` | Модель запасного провайдера |

## Поддерживаемые провайдеры

Любой OpenAI-совместимый endpoint, например:

- Gemini: `https://generativelanguage.googleapis.com/v1beta/openai/`
- OpenRouter: `https://openrouter.ai/api/v1`
- DeepSeek: `https://api.deepseek.com`
- OpenAI: `https://api.openai.com/v1`

## Как это работает

Бот держит историю диалога по каждому чату и передаёт её в LLM.
Ответ модели проходит через постобработку, которая убирает LaTeX-разметку,
и отправляется в ВК (при необходимости — несколькими сообщениями).
Если основной провайдер недоступен, бот автоматически пробует запасной.
