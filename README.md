# VK Homework Bot

Бот ВКонтакте, который решает домашнее задание по тексту, фото или голосовому сообщению.

## Возможности

- **Предметы**: математика, русский язык, физика, химия, биология, география — бот подстраивает ответ под предмет.
- **🧠 Решить задачу** — текст или фото, пошаговое решение.
- **📝 Тест** — мини-тест с 4 вариантами, мгновенной проверкой и счётом в конце.
- **📚 Объясни тему** — краткое объяснение темы + примеры.
- **🎲 Генератор заданий** — тренировочная задача по теме.
- **🧩 Помощь с проектом** — план, идеи и структура проекта.
- **📄 Показать примеры** — примеры решённых задач по теме.
- **✍️ Проверка орфографии** — исправления и пояснения.
- **💡 Советы по учёбе** — лайфхаки.
- **⏰ Напоминания** — напоминание о дедлайне (формат `ДД.ММ ЧЧ:ММ текст`).
- **Сечения**: решает и **дорисовывает** на фото (красным — сечение, синим — вспомогательные линии, подписи точек).
- **Графики**: строит график функции картинкой.
- **История**: «📚 Мои задачи».
- **Лимит**: N задач в день (по умолчанию 5).
- **Админка**: статистика, рассылка, баны, безлимит.
- **Голосовые**: распознаёт речь через Gemini.
- Чистка LaTeX и два провайдера с автопереключением (OpenRouter/Gemini).

## Требования

- Python 3.10+
- Сообщество ВКонтакте с включёнными сообщениями и Long Poll API
- Ключ OpenRouter и/или Gemini
- `matplotlib` и `Pillow` для картинок

## Настройка ВК

1. Создай сообщество → **Управление → Сообщения** → включи «Сообщения сообщества».
2. **Управление → Работа с API → Long Poll API** → «Включено», версия `5.131`,
   типы событий — «Входящее сообщение».
3. **Управление → Работа с API → Ключи доступа → Создать ключ**:
   дай права **«Управление сообществом»**, **«Сообщения сообщества»** и **«Фотографии»**
   (последнее нужно для отправки графиков и дорисованных фото).
4. ID сообщества — внизу раздела «Управление».

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env     # Windows: copy .env.example .env
```

Заполни `.env` (см. ниже), затем:

```bash
python bot.py
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `VK_TOKEN` | Токен сообщества (Long Poll + сообщения + фото) |
| `VK_GROUP_ID` | ID сообщества (число) |
| `LLM_BASE_URL` | Base URL основного провайдера |
| `LLM_API_KEY` | Ключ основного провайдера |
| `LLM_MODEL` | Модель основного провайдера |
| `FALLBACK_BASE_URL` | Base URL запасного провайдера |
| `FALLBACK_API_KEY` | Ключ запасного провайдера |
| `FALLBACK_MODEL` | Модель запасного провайдера |
| `ADMIN_VK` | VK-ник или ID администратора (для ссылки «Помощь») |
| `ADMIN_ID` | **Числовой** VK ID администратора (для админ-команд) |
| `FREE_LIMIT` | Бесплатных задач в день (по умолчанию `5`) |

## Админ-команды

Доступны только пользователю с `ADMIN_ID`:

- `/stats` — статистика (пользователи, задачи, баны).
- `/broadcast <текст>` — рассылка всем пользователям.
- `/users` — список пользователей.
- `/ban <id>` / `/unban <id>` — заблокировать/разблокировать.
- `/grant <id>` / `/revoke <id>` — выдать/снять безлимит.
- `/limit <id> <n>` — задать личный лимит задач в день.

## Поддерживаемые провайдеры

Любой OpenAI-совместимый endpoint, например:

- OpenRouter: `https://openrouter.ai/api/v1`
- Gemini: `https://generativelanguage.googleapis.com/v1beta/openai/`
- DeepSeek: `https://api.deepseek.com`
- OpenAI: `https://api.openai.com/v1`

## Как это работает

Бот держит историю диалога по каждому чату и передаёт её в LLM.
Ответ модели проходит через постобработку, которая убирает LaTeX-разметку,
и отправляется в ВК (при необходимости — несколькими сообщениями).
Если основной провайдер недоступен, бот автоматически пробует запасной.
История задач, лимиты и баны хранятся в `data.json` рядом с ботом.
